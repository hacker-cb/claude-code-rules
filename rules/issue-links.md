# Citing issues and PRs to the user

Every issue / PR / MR number written for the user — chat replies, plans, reports,
tables, Artifacts — is a **link**, and an absolute one.

- **Every occurrence, not just the first.** Repeated mentions and chains
  (`#1063 → #1066 → #1052`) are links too — a table mixing linked and bare
  numbers is the usual failure.
